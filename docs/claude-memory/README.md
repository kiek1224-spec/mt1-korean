# Claude 작업 메모

이 한글화는 사용자와 AI 코딩 도우미(Claude)가 여러 세션에 걸쳐 함께 작업했습니다.
이 폴더는 Claude 가 **세션이 바뀌어도 이어서 일하려고 남긴 메모** 중 이 프로젝트에 해당하는 것만 옮긴 것입니다.
개인 경로는 `%USERPROFILE%` 로 바꿨습니다.

더 자세한 기술 기록은 [`../mt1-hangul-memory.md`](../mt1-hangul-memory.md) 와 [`../../작업롬파일/VERSIONS.md`](../../작업롬파일/VERSIONS.md) 에 있습니다.

| [mt1-hangul-romdiff-method.md](mt1-hangul-romdiff-method.md) | 기록이 없는 빌드를 롬 차분으로 되짚는 방법과 함정 |

| [bizhawk-second-screen.md](bizhawk-second-screen.md) | BizHawk 보조 화면 실험 기록 (매퍼 195 미지원) |
