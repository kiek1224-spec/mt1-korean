https://pareido.jp/wp-content/uploads/nesemu/app/ — 브라우저 NES 에뮬레이터. 여신전생1 을 넣으면
「ダンジョン自動マップ」가 뜨고 계단·엘리베이터·상자·대화 등을 표시한다. 앱 전체가
`assets/index-*.js` 하나에 들어 있다 (ROM 은 드롭해야 화면이 뜬다).

**그 지도 코드는 롬 표를 직접 읽는다** — 우리와 같은 지도($14004)·포인터표($12AF5)를 쓴다.
2026-09-13 에 앱 안 브라우저로 번들을 `fetch` 해서 문자열 검색으로 읽었다.
확인·검증한 뜻은 작업폴더 `mt1-hangul-memory.md` 「레이어의 뜻」 절과 [[mt1-hangul-project]] 참조.

**Why:** 우리 역추적으로는 상자/엘리베이터 레이어를 못 가렸는데 여기서 단서가 나왔다.
**How to apply:**
- 코드를 베끼지 말고 **단서로만** 쓰고, 반드시 우리 롬으로 교차검증할 것
- ★그 코드의 고정뱅크 상수는 **원판 128KB PRG 기준**이다 (`117629`=$CB7D 층표, `121961`=$DC69).
  한글판(256KB)은 고정뱅크가 PRG $3C000 이라 거기서 읽으면 FF 가 나온다 → 사용자에게
  **그 사이트에는 원판 롬을 넣으라**고 할 것
- 그 코드의 RAM: X $0780, Y $0781, 방향 **$0490**(1북 2동 3남 4서)
- automap 에 넣어 **형식을 검증한** 레이어: 10 계단 / 16 엘리베이터 / 22 대화·상자(첫값 32상자) / 20 고정전투(3바이트)
  / **14 워프(텔레포트) — 2026-09-14 추가, 게임 코드 `$FC3A` 로 뜻까지 확정**
- 안 넣은 레이어: 0 지역경계 / 4 턴바닥(코드 `$F4FC` 로 확인) / 6 데미지바닥 / 12 함정(위치·층을 바꾸는 코드 `$FBF7` 확인) / 24 이음매(7바이트)
- ★사이트 해석을 확인할 땐 고정뱅크 `$F51B`(레이어 조회 도우미)의 호출자를 보면 된다 — 레이어id 와 처리 코드가 바로 나온다.
  표는 작업폴더 mt1-hangul-memory.md 「텔레포트 추가」 절
- ★사용자 결정(2026-09-13): **사이트 수준으로 키우지 않는다** — 규모가 커진다. Mesen automap 에
  상자·NPC·보스까지만. 더 넣자는 제안은 사용자가 먼저 원할 때만 할 것.
