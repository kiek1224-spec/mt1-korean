# 던전 상단 사이드 패널 / 전투 커맨드 박스 한국어안
#
# 이 표는 대사 엔진도 이름 훅도 UI 훅도 거치지 않는다.
# 뱅크$05 CPU $BE24 (파일 $0BE34) 에 **5바이트 고정폭 23엔트리**로 박혀 있고,
# 글자는 CHR 뱅크 $02($00~$3F) / $03($40~$7F) 에 구워진 **전용 미니폰트**다.
# 본문 폰트(뱅크4/5)와 완전히 별개라 서로 간섭하지 않는다.
#
# 형식:  idx <TAB> 원문 <TAB> 한글        ('-' 이면 손대지 않는다)
#
# 영어판(Digital Devil Story - Megami Tensei 영어.nes, 매퍼76 원본 뱅킹)이 **같은 표를
# 같은 자리**에 갖고 있다. 그 판의 미니폰트는 라틴이라 뜻을 그대로 읽을 수 있다:
#   Comp Stats Magic Items Talk Jewel / Fight Guard Order Run Yes No Call Bind Auto
# 제약:  한글은 5칸 이하. 남는 칸은 $FF 로 채운다 (원문도 그렇게 한다)
#
# ★idx 4,7,8,9,10,11 은 **쓰이지 않는 엔트리**로 결론냈다 (2026-09-03, 영어판 대조).
#   근거 셋:
#     1) 영어판·스페인어판(완역)에서 이 6개만 **바이트가 원문과 완전히 동일**하다
#     2) 메뉴 정의표 $BDD0(보폭 6)에서 이들을 쓰는 메뉴는 3/4/5/6 뿐인데,
#        `STA $04AD` 14곳 중 즉시값 11곳이 쓰는 메뉴번호는 0 1 2 9 11 12 13 뿐이다
#     3) idx4 는 **어느 메뉴에도 들어 있지 않다**
#   그래서 건드리지 않는다. 그 엔트리가 쓰는 타일은 빌더가 잠금 목록으로 지켜 준다.
# ★idx 14 는 「いちがえ」= 位置替え(전투 중 자리 교체). 미리보기 렌더로 확정.
#   메뉴1 이 `싸움 / 도망 / idx14 / idx22` 라 같은 폰트에 있는 게 증명된다.
# ★idx 6 「ほう玉」=宝玉 -> `구슬`(2026-09-07 통일). ui_words 는 **정적 폰트만** 쓸 수 있어
#   보·옥을 못 쓴다. 구·슬은 정적이라 어디서나 된다. 사용자 실기 화면에서 던전 사이드 패널에
#   같은 미니폰트로 뜨는 것이 확인됐다(2026-09-03).
