# 사람 3화면은 `う<FF>ん`(운) 3바이트 -> LUK. 가운데 <FF> 까지 덮어야 세 글자가 붙는다
# (예전엔 `@..A 1 L` `@..C 1 K` 로 양끝만 박아 화면에 `L K` 로 떴다. 영어판도 LUK 로 채운다)

# ★악마 화면은 5번째가 `うん` 이 아니라 `ぼうき`(ぼうぎょ, 방어) 4바이트라 전역치환에서
#   통째로 빠져 있었다 -> 실기에서 정적폰트 자리의 엉뚱한 한글로 떴다(2026-09-03 사용자 보고).
#   영어판도 같은 자리를 DEF 로 옮겼다.
